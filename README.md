# CYBERNEX V5 ULTIMATE

Static educational website: Cybersecurity + Python.

## Publish
Upload all six files to the root of your GitHub repository (not the enclosing folder). Vercel: Framework Preset **Other**, Root Directory `./`, no build or output command.

## New in V5
- Interactive network operations center: click devices, inspect, isolate simulated suspicious node, reset.
- Python step-by-step visualizer: variables, conditions, loops, functions.
- Teacher scripts displayed automatically in each lesson.
- Brightened backgrounds, accessible mobile layout, preserved V4 introductions, 3D scene and transitions.

## Notes
Requires internet for CDN libraries (GSAP, Three.js, fonts). Simulations are educational only. Python visualizer does not run arbitrary Python.
